Network Security Simulation Project
Overview

This project demonstrates the design and implementation of an enterprise-level network using Cisco Packet Tracer. It includes both foundational and advanced networking concepts, focusing on network design, configuration, and security.

Project Scope

The simulation covers the configuration and implementation of:

VLAN segmentation and inter-VLAN routing
Routing and switching protocols
Access Control Lists (ACLs) for traffic control
Network Address Translation (NAT)
Virtual Private Network (VPN) configuration
Basic firewall and security configurations
Key Skills Demonstrated
Enterprise network design and implementation
Network troubleshooting and optimisation
Security policy enforcement using ACLs
IP addressing and subnetting
Wireless and wired network integration
Problem-solving and system analysis
Tools & Technologies
Cisco Packet Tracer
Cisco networking devices (routers, switches, APs)
TCP/IP networking
VLANs, VTP, NAT, VPN technologies
Documentation

A detailed project report is included in this repository outlining configurations, design decisions, and testing results.
